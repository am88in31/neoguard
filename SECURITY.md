# Security Policy

## Supported Versions
Currently, this project is in the prototype phase. We are working towards a stable v1.0 release.

## Reporting a Vulnerability
Because NeoGuard handles sensitive health-related data (even in simulation), we take security very seriously. 

If you discover a potential security vulnerability (e.g., in the Flask server or data transmission protocols), **please do not open a public issue**. 
Instead, please send an email directly to **am88in31@mail.ir**. 
We will acknowledge your report within 48 hours and work on a patch.
