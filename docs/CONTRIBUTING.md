# Contributing to NeoGuard

First off, thank you for considering contributing to NeoGuard! 

## How Can I Contribute?
- **Reporting Bugs:** Open an issue describing the bug and how to reproduce it.
- **Suggesting Enhancements:** Open an issue describing the feature you want to see.
- **Code Contributions:** Fork the repository, create a new branch, and submit a Pull Request (PR).

## Code Style
- **C++ (Firmware):** Follow the Google C++ Style Guide.
- **Python (ML/Server):** Follow PEP 8 guidelines.
- **Commits:** Use clear and descriptive commit messages.

Please note that due to Intellectual Property (IP) considerations, the core TinyML model and algorithms are not in the public repository, but contributions to the hardware integration and web dashboard are highly welcome.
